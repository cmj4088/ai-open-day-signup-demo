# 模块说明 · 自动化测试（server/test/）

> 版本：v0.3（压测与重构版，与代码同步回填）
> 变更摘要：由「规划态」回填为**实际实现**——文件清单、用例数、运行命令与依赖约束均按代码写实；
> 同时登记 `npm test` 在 Node 24 下的 glob 写法修正，以及 better-sqlite3 升级的动机（见 §六）。

## 一、模块职责

用 **Node 内置 `node:test`**（零新增依赖，符合 Q5「只允许 devDependency」）为后端建立回归安全网，
证明本次重构**未改变对外行为**：

- 覆盖 `server/lib/` 全部纯函数（校验、筛选构造、CSV 转义、时间格式化、编号推导）；
- 覆盖 `server/repositories/` 的 SQL 行为（查重、列表、分页、编号边界、唯一约束兜底、语句缓存）；
- 覆盖 `server/hooks/` 的突发保护逻辑（触发、冷却、拒绝、惰性恢复、快照、重置）；
- 以 **HTTP 集成测试**逐条断言原 5 个接口的**契约未变**（AC1），并补测 `/healthz`、1003、404、5000。

## 三、运行方式

| 场景 | 命令 | 说明 |
|---|---|---|
| 仓库根统一入口 | `npm test` | 实际等价于 `node --test "server/test/*.test.js"` |
| 指定文件 | `node --test server/test/lib.test.js` | 调试单个文件 |

- **glob 必须加引号且由 Node 自行展开**：Node v24 起不再把目录参数当测试路径展开，
  写成 `node --test server/test/` 会报 `Cannot find module`；写成不带引号的
  `node --test server/test/*.test.js` 在部分 shell 下会被提前展开，故统一用**带引号的 glob**。
- 每个测试文件由 `node --test` 在**独立子进程**中运行，互不污染全局状态。
- 测试**不触碰** `data/app.db`：一律使用**内存库**（`dbPath: ':memory:'`）且不启用启动备份。
- 测试**不监听固定端口**：HTTP 集成用 `app.listen(0)` 由内核分配随机端口，避免与 3000/3100 冲突。

## 四、依赖与约束

- **零新增依赖**：只用 `node:test` + `node:assert/strict` + 全局 `fetch`（Node ≥ 18）。
- 不引入 supertest / jest / mocha。
- `engines.node` 固定 `>= 20`（见根 `package.json` 与 `server/package.json`）。
- `_support.js` **必须在任何 `server/` 模块之前被 require**（各测试文件首行即 require 它）：
  它在 import 期设置 `RATE_DISABLED=1` 与 `LOG_REQUESTS=0`，必须早于 `../config` 生效，
  否则并发用例会被 429 截断、测试输出被请求日志淹没。
- 需要触发 Hook 的用例**显式注入** `{ signupBurstGuard: { threshold: N } }`，不改全局默认阈值。

## 六、已知坑与依赖升级记录

- **`formatDateTime(null)` 曾返回 epoch 时间**：`new Date(null)` 与 `new Date('')` 都是**合法时间**，
  故判空必须写在 `new Date` **之前**。该缺陷由 `lib.test.js` 暴露并已修复（见 `lib/datetime.js`）。
- **`npm test` 随机原生崩溃（已解决）**：本机 Node v24 下出现 `Assertion failed: (env) != nullptr`，
  退出码 134/1，栈顶 `Statement::scalar deleting destructor`。经最小复现（语句缓存 + 事务 + iterate）
  定位为 better-sqlite3 v11 的原生析构缺陷，`process.exit(0)` / `--test-isolation=none` / 不调 `db.close()`
  均无法根治。**经用户授权**将 `better-sqlite3` 由 `^11.3.0` 升级至 `^12.11.1` 后，`npm test` 连跑 6 次全绿。
  该升级是 Q5「dependencies 一字不动」的**唯一例外**，来源为用户明确授权。
