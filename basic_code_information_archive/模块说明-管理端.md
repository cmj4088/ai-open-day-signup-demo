# 模块说明 · 管理端（admin.html）

## 一、模块职责

管理端是面向活动组织者的独立入口，用一个 `admin.html` 承载，用于：

1. 总览全部报名名单；
2. 按 **身份 + 场次 + 关键字** 组合筛选（**筛选由服务端执行**，保证与导出结果完全一致）；
3. 提供**导出按钮**：按当前筛选条件**真实下载 CSV**（UTF-8 BOM）。

管理端**无登录**，通过**独立网址**直接进入。数据只读为主，通过 API 客户端 `store.js` 的 `list()` 获取。

## 二、载体文件

- `admin.html`：页面结构（统计条 + 筛选区 + 名单表格）。
- `assets/js/admin.js`：下拉渲染、按筛选调后端取名单、表格渲染、导出触发下载。
- `assets/css/style.css`：样式。

## 三、页面构成

### 3.1 顶部区

- 标题：`AI 应用教学开放日 · 报名名单管理`（卡片内标题为「报名名单」）；
- **统计条**（`#stat-bar`）：展示**当前筛选后**的记录条数，文案格式为 **「共 N 条报名」**（不含总数，仅筛选后条数）。

### 3.2 筛选区

| 筛选项 | 控件 | 取值 | 匹配方式 |
|---|---|---|---|
| 身份 | 下拉（`#filter-role`） | 全部身份 / 教师 / 学生 / 其他 | 精确匹配 |
| 场次 | 下拉（`#filter-session`） | 全部场次 / 上午场 / 下午场 | 精确匹配 |
| 关键字 | 文本输入（`#filter-keyword`，占位「姓名或手机号关键字」） | 任意字符串 | 对 姓名 / 手机号 / 院系 做包含匹配（不区分大小写、忽略首尾空格） |

- 多个条件之间为**与（AND）**关系；
- 条件变更后立即重新渲染表格（实时筛选：`change` / `input` 事件触发）；
- 提供「**重置**」按钮（`#btn-reset`），一键清空三个筛选控件回到全部；
- 提供「**导出名单**」按钮（`#btn-export`），见第四章。

### 3.3 名单表格

表格列共 **6 列**（顺序固定）：

| 列 | 含义 | 说明 |
|---|---|---|
| 报名时间 | `createdAt` 格式化 | 统一格式化输出（`YYYY-MM-DD HH:mm`；非法值展示「—」） |
| 姓名 | 报名人姓名 | 空值展示「—」 |
| 身份 | 教师 / 学生 / 其他 | 以徽标（badge）展示；空值/未匹配展示「—」 |
| 院系 | 院系名称 | 空值展示「—」 |
| 手机号 | 11 位手机号 | 空值展示「—」 |
| 参加场次 | 上午场 / 下午场 | 徽标展示场次标签，后附时间段（如「09:00–12:00」） |

- 无符合条件的数据时，表格下方展示空状态提示（`#empty-notice`）：**「暂无报名记录哦」**。

## 四、导出按钮（真实下载）

- 位置：**筛选区内**（与其他筛选控件同排）；
- 行为：读取当前筛选条件 → 调 `Store.exportUrl(filters)` 生成地址（`GET /api/registrations/export?role&session&keyword`）→ 用隐藏 `<a>` 触发下载；
- 后端返回 `Content-Disposition: attachment` 与 **UTF-8 BOM** 的 CSV，文件名形如 `报名名单-YYYYMMDD.csv`；
- **导出内容严格等于当前筛选结果**（同一套服务端过滤逻辑），变化时在页面顶部提示条展示 **「已按当前筛选条件开始下载 CSV，请查看浏览器下载目录」**，**4 秒后自动隐藏**；
- 约束：不引入第三方导出库，导出内容由后端生成。

## 五、交互流程

1. `Store.ready` 就绪 → 渲染身份/场次下拉 → 绑定事件 → 调 `list()` 取全部记录 → 渲染统计条与表格（加载中显示「加载中…」）；
2. 用户调整身份 / 场次 / 关键字 → 携带三条件调 `list(filters)` → 服务端过滤 → 重渲染统计条与表格；快速连续调整时仅采纳**最后一次**请求结果（请求序号守卫），避免旧响应覆盖新结果；
3. 点击「重置」→ 清空三个筛选控件 → 重新拉取全部；
4. 点击「导出名单」→ 按当前筛选触发 CSV 下载 → 展示提示条，4 秒后自动隐藏；
5. 加载失败（网络/服务异常）→ 统计条显示「加载失败」，空状态区展示可辨识的错误文案（区别于「无数据」）。

## 六、依赖与约束

- 依赖 API 客户端 `list(filters)` / `exportUrl(filters)` / `roleLabel()` / `sessionLabel()` / `SESSIONS` / `ROLES`；
- 场次/身份展示文案与字典一致；
- **无登录、无鉴权**（用户明确选择，保持 Demo 状态）；后端以**限流**降低无鉴权风险，演示结束后应关闭穿透隧道；
- 导出由后端生成 CSV，前端不拼装文件内容。
