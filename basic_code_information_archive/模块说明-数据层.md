# 模块说明 · 数据层（store.js）

> **版本变更（v0.2）**：本模块已由「localStorage 读写封装」重构为「**后端 API 客户端**」。
> v0.1 的 `localStorage` 实现仅保留历史说明于 `.trae/specs/build-open-day-signup-demo/spec.md`。

## 一、模块职责

`assets/js/store.js` 是前端**唯一的数据出入口**，统一封装对后端 REST API 的 `fetch` 调用，向上层（用户端 / 管理端）暴露简洁接口。约定：**业务页面不得直接 `fetch`，一切读写经由本模块**。

## 二、接口基地址

- 前端与后端**同源**（由 Node 服务统一托管 `user.html` / `admin.html` / `assets/`），故使用**相对路径**（`API_BASE = ''`），无需配置跨域域名。
- 因此**必须通过服务地址打开页面**（如 `http://localhost:3000/user.html`），不可用 `file://` 直接双击打开。

## 三、字典

| 字典 | 来源 | 说明 |
|---|---|---|
| `SESSIONS` | **后端接口** `/api/sessions` | 页面就绪前用兜底值渲染，接口返回后覆盖，保证与服务端一致 |
| `ROLES` | **前端常量** | 纯 UI 枚举（teacher/student/other），无服务端增删需求，故内聚维护 |

- `Store.ready`：一个 Promise，在 `/api/sessions` 拉取完成（或失败回退）后 resolve。页面应 `Store.ready.then(...)` 后再渲染下拉，避免用到兜底字典。

## 四、数据结构（API 记录）

后端返回的记录字段（驼峰）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | 主键自增 |
| `regNo` | string | 报名编号，如 `REG202610060001` |
| `name` | string | 姓名 |
| `role` | string | 身份，可空 |
| `department` | string | 院系，可空 |
| `phone` | string | 手机号（11 位，全局唯一） |
| `session` | string | 场次 `morning` / `afternoon` |
| `createdAt` | string | 报名时间，ISO 字符串 |

## 五、对外 API

| API | 签名 | 说明 |
|---|---|---|
| `ready` | `Promise` | 场次字典就绪信号 |
| `list(filters)` | `({role?,session?,keyword?}) => Promise<Record[]>` | 名单列表（筛选走服务端，三条件 AND）；失败 **reject** |
| `getByPhone(phone)` | `(string) => Promise<Record \| null>` | 按手机号查询；命中返回记录，未命中 `null`；失败 **reject** |
| `add(record)` | `(record) => Promise<{ok,data?,reason?,message?}>` | 提交报名；**永不 reject**，便于页面统一处理 |
| `exportUrl(filters)` | `(filters) => string` | 生成导出下载地址（浏览器据 `Content-Disposition` 下载 CSV） |
| `sessionLabel(key)` | `(string) => string` | 场次键 → 展示文案；空/未匹配返回「—」 |
| `roleLabel(key)` | `(string) => string` | 身份键 → 展示文案；空/未匹配返回「—」 |
| `SESSIONS` / `ROLES` | 数组 | 字典（`SESSIONS` 为 getter，返回最新值） |

### `add` 的返回约定

| 场景 | 返回值 |
|---|---|
| 成功 | `{ ok: true, data: Record }` |
| 手机号重复（后端 `code=1002`） | `{ ok: false, reason: 'duplicate', message: '该手机号已报名，请勿重复提交' }` |
| 参数校验失败（后端 `code=1001`） | `{ ok: false, reason: 'invalid', message: <后端文案> }` |
| 网络异常 | `{ ok: false, reason: 'network', message: '网络异常，请稍后重试' }` |

## 六、约束

- 仅使用原生 `fetch` 与 ES6，禁止引入第三方 HTTP 库；
- 所有路径拼参使用 `encodeURIComponent`，防注入与乱码；
- 不再使用 `localStorage`，前端不持有任何持久化数据；
- 展示文案（场次/身份标签）统一由字典提供，禁止页面内硬编码第二套。
