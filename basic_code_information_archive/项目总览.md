# 项目总览 · AI 应用教学开放日报名系统

## 一、项目简介

本项目是学校「AI 应用教学开放日」报名系统的**前后端分离实现**，用于演示并实际承载报名全流程。相比 v0.1 纯静态 Demo（数据存浏览器 `localStorage`、导出为演示提示），v0.2 升级为**真实可用**：后端 Node.js + Express 提供 API、SQLite 持久化、管理端真实导出 CSV，并可部署到副机经内网穿透对外访问。

- 演示目标：跑通「用户报名 → 成功回执 → 手机号查询」与「管理端名单总览 / 筛选 / 导出 CSV」两条完整链路，且数据**重启不丢**。
- 使用场景：校园开放日现场演示、教学示例、原型验证。
- 文案基调：活泼亲切。

## 二、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 结构 | 纯 HTML5 | 两个入口页：`user.html`、`admin.html` |
| 样式 | 原生 CSS | 统一样式表 `assets/css/style.css`（校园深蓝主题） |
| 前端逻辑 | 原生 JavaScript（ES6） | 无框架；`assets/js/store.js` 为 API 客户端 |
| 后端 | **Node.js + Express** | `server/` 目录，提供 REST API 并托管前端静态资源 |
| 存储 | **SQLite（better-sqlite3）** | 单文件 + WAL 模式 + 启动自动备份（保留 7 份） |
| 部署 | Linux 副机 + 内网穿透 | 见 `docs/部署文档.md` |
| 构建 | 无前端构建 | 前端零构建；后端仅 `npm install` |

## 六、如何运行

### 方式一（推荐）：后端服务统一托管

```bash
# 1) 安装后端依赖
cd server && npm install && cd ..

# 2) 启动服务（默认端口 3000）
cd server && npm start
```

浏览器访问：

- 用户端：`http://localhost:3000/user.html`
- 管理端：`http://localhost:3000/admin.html`

后端同时托管前端静态资源与 API，**同源**，无跨域与 `file://` 源隔离问题。

### 方式二：本地启动脚本

- Windows：双击 `start.bat`
- Linux：`bash start.sh`

### 数据重置

删除 `data/app.db` 后重启服务即可回到空库（空库不注入种子数据）。

## 七、关键业务定稿（速查）

- 场次共 **2 场**，同主题「AI 应用教学开放日」，仅时间不同：**上午场 09:00–12:00**、**下午场 14:00–17:00**；地点统一 **报告厅 A**；**无容量概念**。
- 报名字段：姓名、身份（教师 / 学生 / 其他）、院系、手机号、参加场次。
- 必填校验仅卡 **姓名 / 手机号 / 参加场次**；身份、院系可留空；校验在**失焦时实时触发**，错误提示为**红色中文**、显示在字段下方。
- **手机号全局唯一**：前端预检 + 后端 DB 唯一索引兜底；重复提示「该手机号已报名，请勿重复提交」。
- 报名编号：`REG + YYYYMMDD + 4 位当日流水`（如 `REG202610060001`）。
- 管理端**无登录**（用户明确选择，保持 Demo 状态）；导出为**真实下载 CSV**（UTF-8 BOM），严格按当前筛选条件。
