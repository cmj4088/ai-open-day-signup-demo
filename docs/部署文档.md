# 部署文档 · AI 应用教学开放日报名系统（副机 + 内网穿透）

> 目标：把本项目部署到**自有 Linux 副机**，并通过**临时内网穿透**让外网用户访问。
> 对应 PRD S7 与 AC1。副机无公网 IP，故采用穿透方案。

---

## 一、前置条件

| 项 | 要求 | 检查命令 |
|---|---|---|
| 操作系统 | Linux（Ubuntu / Debian / CentOS 均可） | `uname -a` |
| Node.js | **≥ 18**（推荐 20 LTS 或以上） | `node -v` |
| npm | 随 Node 安装 | `npm -v` |
| 网络 | 能访问 npm 源与外网（穿透需联网） | `curl -I https://registry.npmjs.org` |

> 副机若未装 Node：Ubuntu/Debian 可执行 `sudo apt update && sudo apt install -y nodejs npm`；
> 更推荐用 nvm 安装：`curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash` 后 `nvm install 20`。

## 二、上传项目到副机

任选一种：

```bash
# 方式 A：scp 从本地上传（在本地机器执行）
scp -r ai-open-day-signup-demo user@副机IP:/home/user/

# 方式 B：git clone（若已推到仓库）
git clone <仓库地址> ai-open-day-signup-demo

# 方式 C：U 盘拷贝
```

> **注意**：`node_modules/` 与 `data/` 属于本地/运行时产物，**不需要上传**；`data/` 会在副机首次启动时自动创建。

## 三、安装依赖并启动

```bash
cd ai-open-day-signup-demo
bash start.sh
```

`start.sh` 会自动：① 无 `node_modules` 时执行 `npm install`；② 以 `PORT`（默认 3000）启动服务。

看到如下输出即启动成功：

```
AI 应用教学开放日报名系统 · 后端服务已启动
监听端口 : 3000
用户端   : http://localhost:3000/user.html
管理端   : http://localhost:3000/admin.html
```

先在副机本机验证：

```bash
curl -s http://localhost:3000/api/sessions
```

### 后台常驻运行（二选一）

```bash
# 方案 A：nohup（简单）
nohup npm start > app.log 2>&1 &      # 在 server/ 目录执行

# 方案 B：pm2（推荐，可自启与看日志）
sudo npm install -g pm2
pm2 start server.js --name open-day-signup
pm2 logs open-day-signup
pm2 save && pm2 startup              # 开机自启
```

## 四、内网穿透（ngrok）

1. 注册 ngrok 账号并获取 authtoken：<https://dashboard.ngrok.com/get-started/your-authtoken>

2. 在副机安装并配置：

```bash
# 下载（按架构选择；x86_64 用 amd64）
curl -sSL https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz -o ngrok.tgz
tar -xzf ngrok.tgz
sudo mv ngrok /usr/local/bin/

# 绑定账号
ngrok config add-authtoken <你的AUTHTOKEN>
```

3. 开启隧道（转发到本机 3000 端口）：

```bash
ngrok http 3000
```

4. 记下输出的公网地址，形如：

```
Forwarding  https://xxxx-xx-xx-xx-xx.ngrok-free.app -> http://localhost:3000
```

5. **外网访问**（他人设备用 4G/其他网络打开）：

| 页面 | 地址 |
|---|---|
| 用户端报名页 | `https://xxxx-xx-xx-xx-xx.ngrok-free.app/user.html` |
| 管理端名单页 | `https://xxxx-xx-xx-xx-xx.ngrok-free.app/admin.html` |

> ngrok 免费档首次访问可能出现中间提示页，点击继续即可。

## 五、收尾（重要）

- **演示结束后立刻关闭隧道**：在 ngrok 前台按 `Ctrl+C`，避免管理端名单（含手机号）长期暴露在公网。
- 管理端**无登录**是本次的明确选择；若需长期对外，建议后续加鉴权或收紧 `CORS_ORIGIN`。
- 停止服务：`Ctrl+C`（前台）或 `pm2 stop open-day-signup`（pm2）。

## 六、数据与备份

- 数据文件：`data/app.db`（SQLite）。
- 备份文件：`data/backups/app-YYYYMMDD-HHmmss.db`，**每次启动自动备份，仅保留最近 7 份**。
- 恢复：停服后把某个 `data/backups/app-*.db` 覆盖回 `data/app.db` 再启动即可。
- 重置为空库：停服后删除 `data/app.db*`（含 `-wal`/`-shm`）再启动（空库不注入种子数据）。

## 七、常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 访问穿透网址 502 / 连接被拒 | 后端未启动或端口不符；确认 `npm start` 在运行且 `ngrok http` 端口与 `PORT` 一致 |
| 副机本机可访问、外网不可 | 隧道未开或已断；重启 `ngrok http 3000`（免费档域名会变，需重新分发网址） |
| 报名失败提示「网络异常」 | 前端与后端不同源或后端挂了；确认是通过服务地址打开页面，而非本地 `file://` |
| 端口被占用 | 换端口：`PORT=8080 npm start`，并同步 `ngrok http 8080` |
| `npm install` 卡在 better-sqlite3 编译 | 缺少构建工具：`sudo apt install -y build-essential python3` 后重试；或确认 Node 版本 ≥18 |
| Excel 打开 CSV 中文乱码 | 导出已带 UTF-8 BOM；若仍异常，改用「数据 → 自文本」并选 UTF-8 导入 |

## 八、可选升级（长期稳定网址）

临时穿透适合演示，若要**固定网址**与更好稳定性，可换：

- **Cloudflare Tunnel**（免费、稳定、自动 HTTPS）：`cloudflared tunnel --url http://localhost:3000`
- **frp**（自建服务端，需一台有公网 IP 的机器）
- **Nginx + 域名 + 证书**（若有公网服务器）

本项目后端已 `app.set('trust proxy', 1)`，可直接置于上述反向代理之后。
